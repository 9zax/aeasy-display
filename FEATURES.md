# Features

<p><b>English</b> · <a href="FEATURES.th.md">ภาษาไทย</a></p>

- Second display over USB-C or Wi-Fi (`aeasy wifi`)
- Real macOS extended display — drag windows to it, not just mirroring
- Touchscreen: tap to click, drag windows with a finger
- Auto-rotation — portrait/landscape follows the device
- Up to 3 sources at once as arrangeable, resizable panes
- Single-app window mirroring (`aeasy mirror <App>`)
- Hardware-encoded H.264 / HEVC, Retina-crisp
- Adaptive quality — bitrate/fps step down live when the decoder lags
- One-shot low-latency preset for slow devices (`aeasy tune`)
- Settings GUI: fps, bitrate, resolution, sources, pane layout (`aeasy config`)
- Plug-and-play: cable watcher auto-starts and auto-reconnects
- Menu bar tray icon: status, start/stop, settings
- Android 8+ phones and tablets
- iPhone & iPad viewer (beta)
- Minimal permissions — Android app needs only `INTERNET`
- Free, open source (MIT), no accounts
